# Sri Lankan synthetic FHIR terminal

The standalone application is in [nehr-synth](nehr-synth/README.md).
It generates local synthetic FHIR R4 resources against the pinned published
`fhir.lk.nehr` suite. Receiver compatibility remains unconfirmed.

See the [application README](nehr-synth/README.md) for installation, CLI/TUI use,
profile coverage, validation evidence and known limitations.
